## Что в ветви prolog

Программа на Prolog решает задачу:

Серый Волк, Ниф-Ниф, Наф-Наф и Нуф-Нуф стали филателистами. Каждый из них собирает марки определённой тематики: один — флору, другой — спорт, третий — космос, а Волк — фауну. Вся компания собралась за столом в доме Волка. При этом:

- Волк сидит слева от Нафа.
- Ниф — справа от того, кто собирает марки про космос.
- Нуф сидит напротив Нафа и при этом совсем не интересуется спортивной тематикой.

**Вопрос:** можно ли определить, какие марки собирает каждый из четырёх героев?
